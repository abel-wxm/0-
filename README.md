1.一款可以告别重复文件的管理软件
2.我们经常遇到如下问题（以照片举例）：
当拍摄了许多照片，存储到电脑上时，需要根据其不同属性对其分类。比如，按时间分类，按滤镜分类、按人物分类等等。如果用不同文件夹去存储这种分类就会造成文件重复保存，而且在一个文件夹里编辑了其他文件夹的还是老版本。尽管这在某些软件里可以通过打标签的方式解决，但每一个标签只显示该标签的内容，要和其他属性的对比，就只能反复切换很不方便。如果都是文件夹，想看哪个打开哪个，或者几个同时打开并排对比多方便；或者当我们下次备份手机照片时，也许有些已经备份过了，但我们忘记了，也会造成重复文件。如果每次都有新文件备份，都加入重复提醒（无论在哪个文件夹）也可以避免。
“0重复文件管理”对于同一个文件，在不同文件夹出现时，实际只在一个地方存储，其他文件夹只是其映射，但无论在哪个文件夹对该文件编辑、删除等效果一致（区别于快捷方式）。
